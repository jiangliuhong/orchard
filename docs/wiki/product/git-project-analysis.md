# Git 项目分析与存储空间

状态：已实现；更新日期：2026-11-10。实施与验收记录见 [Git 项目 Agent feature](../../features/2026-11-10-git-project-agent/implementation.md)。

## 前置条件

- Orchard 服务所在主机安装 Git、OpenSSH，以及已配置模型的 Pi 或 Codex CLI。
- 项目仅支持 SSH Git 地址和固定分支，不支持运行输入覆盖地址、分支、凭据或本机路径。
- 管理员在实际数据目录 `project-git/ssh-profiles.json` 配置本机 SSH 引用。文件权限为 0600，示例：

```json
[
  {
    "id": "git-host",
    "name": "Git 主机",
    "host": "git.example.com",
    "port": 22,
    "user": "git",
    "identityFile": "/absolute/path/to/private-key",
    "knownHostsFile": "/absolute/path/to/known_hosts",
    "useAgent": false,
    "revision": 1
  }
]
```

私钥必须是运行账户所有的普通文件，权限仅本人可访问，父目录受控，不接受符号链接。通过可信渠道核对主机指纹并维护 known_hosts；未知或变化的指纹阻止连接。加密私钥需预先解锁到服务可访问的 ssh-agent，然后使用 `useAgent: true`。修改档案时递增 revision。网页不上传、生成或返回私钥，也不返回凭据文件路径。

本机指服务主机，不是浏览器所在设备；服务模式不一定继承桌面终端的 agent 环境。SSH 私钥本身不决定 pull/push 权限，远端授权由 Git 服务端控制。

## 配置与运行

1. 设置 → 项目仓库，新建稳定项目 ID、名称、SSH 地址、分支和档案引用。
2. 明确接受本机文件/命令/凭据访问及源码发送风险，再启用并保存。
3. “检测已保存配置”仅检查读取权限和分支，不验证推送权限。不能自动接受未知主机。
4. Agent 节点选择“项目上下文”，使用支持项目分析的 Agent 模型配置，配置提示词和输出 Schema，然后保存、测试或发布。
5. 运行详情显示准备阶段、来源分支、固定 SHA、准备耗时和未展开项；业务 JSON 可继续通过节点输入或顶层 result 绑定消费。

Pi、Codex 项目调用都能使用原生工具；普通节点和创作对话的工具策略不变。独立可写目录不是沙箱。Agent 可能访问宿主文件、环境、凭据和网络，Orchard 不保证阻止 push 或其他外部副作用；不要以“只读分析”理解此功能。

## 生命周期与失败

- 入队固定项目和凭据档案引用配置；准备时获取远端分支并固定 commit，不执行 pull/merge。
- bare 缓存按项目修订长期保留；并发运行不共享工作树。源码逐 blob 物化，不使用 checkout filters/hooks，不下载子模块或 LFS 对象，不创建提交中的符号链接。
- 来源记录与业务输出分开，保存在现有 attempt 执行 JSON 中。项目、SSH 引用和缓存不导出到配置 Git；跨设备恢复缺少有效本机项目时，预览会阻止相关工作流应用，先配置再重新预览。
- 网络失败不使用旧缓存；失败、超时、取消不会自动重新分析。成功、失败、取消后删除临时快照/会话，Agent 修改不保留；缓存保留。
- 清理失败保留租约并重试。重启先协调数据库运行状态，再清理失去持有者的资源；若发现仍存活或无法确认的进程 PID，保守保留目录，不盲目杀死 PID 或删除工作区。
- 不提供项目物理删除、存储配额、容量 GC 或清理按钮。可禁用项目；已经入队的任务仍沿用入队配置。

## 存储空间

设置 → 存储空间显示实际数据目录、分配空间估算、逻辑字节、普通文件数、分类、项目明细、卷总容量与运行账户可用空间。“刷新统计”复用实例内的活动扫描，不启动重复扫描；离开页面只停止轮询。

统计只读，不读源码/密钥内容、不 checkpoint/VACUUM 或 Git GC。隐藏文件计入，不跟随符号链接，不跨设备，硬链接仅计算一次；项目孤立缓存按 ID 展示，共享目录元数据及无法归属的临时资源单独列出。项目明细是缓存/临时分类下钻，不再与分类合计相加。

统计不是一致性快照；错误、权限不足和中断会标为部分结果，显示“已统计 + 未知”，不是把不可读取的内容当成零。allocated 不支持时明确降级到逻辑大小。压缩、reflink 和共享块不能精确归属，占用估算不等于可释放空间。外部密钥、Provider 用户目录及外部备份不计入。
