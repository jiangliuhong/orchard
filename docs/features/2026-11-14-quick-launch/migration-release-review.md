## 结构与转换边界

- 增量 DDL 只追加四表和对应索引。全新安装继承 v11 初始化结构并使用同一增量定义。现有 runs、script_tests 和节点记录通过底层二元组关联。
- 增量文件只处理结构，迁移执行器负责事务、回填和校验。源身份、版本和结构通过核对后，在迁移副本内添加结构，按底层类型和 ID 回填。全部校验通过才设置 user_version 为 12，并进入现有安装和账本提交流程。
- 回填数据限安全摘要和可验证标识，缺省来源为 legacy_unknown。使用独立历史请求作用域和确定性 ID 建立去重。旧浏览器文件历史的 ID 保留为底层关联，旧记录缺少关联或输出时如实标记。回填产生零条 outbox 派发记录。
- 分组规范化、树深及成环检测、revision 比较、生命周期迁移、事件序号单调性、租约 fencing 和脱敏在应用写事务内校验。DDL 负责引用约束、状态枚举、成对字段、唯一性及活动执行占用，具体业务校验随实现阶段验收。
