# 快速执行实施任务拆分

状态 **审核通过 · 编码中** · 2026-11-14

依据 [设计](./design.md) 和 [数据库审核稿](./database-review.md)。任务编号用于依赖和验收。T1 的 v12 候选已接入并冻结，见[迁移审核稿](./migration-release-review.md)。按用户要求，先完成全部编码，再统一进行测试及迁移演练。实际目录迁移须单独确认。

T2 可与 T1 的审核准备并行，T5 与 T6 可在统一执行接口稳定后并行。优先打通三类执行接收、派发和落库，再接页面。任何改变结构、升级源或恢复方式的决定回到数据库审核稿。完成标准是接口、持久状态、已审核交互及迁移演练相符，保留原有调用方兼容。

## 编码与验证进度

- v12 迁移、回填映射、浏览器历史快照、独立新装基线与发布清单已接入。
- 卡片、分组、引用允许名单、执行登记、工作流、脚本和网页桥接适配已接入产品服务；快速执行和统一运行记录页面使用正式 API。
- 工作流和脚本沿用引擎队列。网页桥接使用持久领取凭证、租约和派发标记，重启后将结果不明的已派发请求标为待确认。独立后台工作器定期领取任务和对账，启动请求只登记队列。已确认结果的写入可重试，过期的未派发领取可归还队列。已派发请求仅按稳定调用 ID 核对本地可信结果，外部结果不可查证时等待人工处理。
- 网页桥接兼容页暂保留受原隐私策略保护的可回填历史，使用统一调用 ID 去重。统一摘要无 500 条上限。旧回填细节仍依赖兼容历史。
