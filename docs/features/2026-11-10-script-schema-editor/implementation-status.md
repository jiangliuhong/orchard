## 交付范围

- 脚本输入／输出 Schema 字段树编辑，支持根类型、嵌套对象与同构数组、必填、说明、常用约束、默认值及 x-ui／x-history。
- 保留 JSON 模式；复杂 Schema 无损回退，重复 JSON 键与非法约束阻止保存。字段视图展示深度护栏为 12 层，不截断保存原始定义。
- 类型切换、删除字段和 Shell 进程输出模板替换均需确认；发布版本只读查看，不改变已有执行协议。
- Agent 提示词同步参数、实现和结果契约；提案展示字段／约束差异与历史保护放宽警告，保留完整 JSON／源码差异，确认后原子应用。
- 测试参数表单与高级 JSON 输入；顶层参数支持普通／加密字典整个 Key 引用，保留 JSON 类型。不支持根引用、嵌套目标、数组元素或字典内部 Pointer，服务端同样拒绝。
- 复用桥接字典选择器，提供搜索、重选、解除引用；保留桥接原有字符串凭据限制。
- 测试入队固定脚本快照与字典版本，合并代码依赖和参数依赖，沿用既有版本绑定表和 GC 保护。
- 历史恢复允许记录的值与字典引用；缺失的手动值需要补填，复用不自动执行，下一次测试使用当前字典版本。
- 手动值默认记录，显式禁止才不记录。禁止记录的参数只驻留进程内存；成功、失败、取消或关闭后释放，重启后中断并要求重新填写。前端提交后也清除禁止记录的值及其请求缓存。
- 加密引用或禁止记录的手动参数使整次测试隐藏输入／输出／日志；Agent 只收到安全上下文。
- 测试请求改用现有本机 HMAC 密钥计算幂等摘要，回执只保存摘要与测试 ID，兼容旧回执重试；大历史输入沿用产物读取。
- 实际页面检查发现窄屏原有双栏挤压编辑器，已改为核心工作区优先、Agent 在下方的可滚动布局，保存操作可达。

## 已知边界

- 字段编辑器并非完整 JSON Schema 设计器；复杂结构使用 JSON，不自动降级契约。
- 非对象根输入及无法静态识别顶层属性的复杂 Schema 可手动测试，但首版不支持字典引用。
- 普通值允许记录并不等于加密；敏感参数应显式禁用记录或引用加密字典。
- 脚本仍拥有启动用户的系统权限，受控输入与日志保护不等于操作系统沙箱。
