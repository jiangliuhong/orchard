## 已确认范围

1. single 严格一轮；工作流、脚本、浏览器工具维护页面全部固定原生 multi。
2. CLI 自行管理上下文；平台不重放、摘要或重建历史，不每轮注入完整草稿。
3. 知识全部内置，随包安装初始化到唯一共享只读 workspace；新建对话不复制 AGENTS.md/Skills。设置只读，知识更新后旧对话只读，使用新版须新建。
4. 第一版提供跨资源定义、源码和引用关系查询；不开放跨资源运行数据或平台写工具。
5. 提案沿用原应用流程，必须携带查询所得 revision；宿主反馈实际应用结果和资源变化。
6. Provider 固定；空闲时允许同 Provider 内切换模型并保持原生上下文。
7. 平台直接删除对话、消息、未应用提案和原生上下文，不做归档或恢复；须明确确认，失败保留引用与阶段以便重试，业务资产与运行记录保留。
8. 设置仅展示磁盘占用；保留运行资源释放，不提供历史清理、配额驱逐或清理 UI。
9. 升级明确确认后重置旧 Agent 数据，不导入旧对话，保留已应用业务资产及运行记录。
10. 原生会话由可扩展 Provider 封装；Runtime 只保存不透明、带版本的引用，不解析 CLI ID 或 session 文件。
11. 共享 cwd 不共享上下文/工具身份；会话删除和释放不得删除共享目录。项目等独立执行场景按需使用私有 runtime 目录。
