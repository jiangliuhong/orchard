# 统一 Agent 对话、知识与工作区

- 状态：设计中，待评审；创建日期：2026-11-11。
- [完整方案](./design.md)：严格 single/multi 语义、全场景统一运行时、知识打包初始化、工作区、清理与配额、API/UI、兼容迁移和验收。
- 数据库结构变更尚未审核批准，本 feature 当前仅包含设计文档。

## 核心评审项

1. single 只允许一个逻辑轮次，再次请求创建新对话。
2. multi 统一使用原生持久上下文；历史重放只用于显式重建。
3. 知识在源码维护、随安装包发布、数据目录初始化，并按对话固定版本。
4. 对话历史、原生会话与可再生成工作区分别管理；清理不隐式破坏可恢复性。
5. 旧脚本/Web Bridge 对话继续前需显式重建；旧原生会话保持原 cwd。
6. 数据库模型、保留默认值和 CLI 知识隔离能力须在实施前完成评审。
