# 字典软删除与彻底删除交付验证

日期：2026-11-11。状态：已完成编码与专项验证。

## 实现范围

- 列表、详情：删除确认；已删除列表；名称确认彻底删除；请求中禁用、错误提示、成功刷新。已删除详情只读。
- DELETE /api/dictionaries/:id：requestId、expectedRevision；可选 permanent、confirmationName。所有删除请求使用本机同源/令牌守卫；无值请求无需解密，缺失密钥时仍可删除。
- 软删除保留名称与历史版本；当前引用阻止软删除。彻底删除需要已软删除、无任何定义引用或运行/测试绑定；扫描不完整时拒绝。不修改其他业务记录。
- 包括网页桥接凭据和固定脚本版本间接引用；静态校验、执行入队、凭据解析与引用选择器排除已删除字典；历史固定绑定仍可读取。
- Git 导出排除已删除字典；导入已删除的同 ID 对象拒绝，避免静默复活。
- 新增 v9→v10 迁移，保留 v9 及之前迁移身份；完整审核记录见 [schema-review-v10.md](./schema-review-v10.md)。
