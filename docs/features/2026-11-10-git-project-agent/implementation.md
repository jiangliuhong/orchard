# 实施与交付记录

日期：2026-11-10。状态：已完成编码交付；最终回归与外部故障矩阵单列，不等同于所有验收场景均已通过。

## 已接入的功能

### 项目、SSH 与仓库

- `src/project-git/` 实现本机原子 JSON 项目配置、SSH 引用校验、风险策略版本、修订冲突和异步连接检测。首期只提供禁用，不提供物理删除，因此不会绕过历史/活动引用而删除项目。
- SSH 地址/分支与档案身份匹配，控制字符、选项注入和非 SSH 协议拒绝；保留 SCP 相对路径语义，受控 launcher 指定端口、私钥和主机信任，不继承用户 SSH 配置，不回退密码或其他身份。
- SSH 文件必须为普通受控文件；未知或变化的主机密钥失败。原始命令和 stderr 不返回 API/事件。
- clone staging 原子就位、bare 缓存按项目修订保留；项目锁中 fetch、解析 SHA、建立 lease/ref，随后独立物化。不开启 hooks/filters/LFS/子模块下载，不使用共享工作树，不增加仓库或文件配额。
- 源码通过 binary-safe Git plumbing 逐 blob 写入，保留可执行属性，拒绝路径穿越、管理目录、大小写/Unicode/平台别名冲突，跳过符号链接与子模块并记录未展开项。
- 所有宿主管理的缓存、staging、运行固定记录、源码快照、租约及项目会话位于实际 data-dir；不硬编码默认目录。

### 执行与恢复

- 工作流 Agent 契约增加 `project: { projectId }`，嵌套未知字段拒绝。发布/入队检查本机依赖、风险与 Provider 能力；配置恢复预览对草稿和全部不可变版本检查项目依赖，失效预览不能直接应用。
- 入队在现有事务内先写受控内部运行文件，保存项目和 SSH 引用配置；后续禁用/修改不悄悄换仓库。SQLite 入队失败不会产生可执行任务；启动回收无对应活动任务的文件。
- 准备时固定 SHA，尽早保存 attempt 来源；业务输出仍只由 outputSchema 决定。项目默认准备与分析合计 10 分钟，沿用取消、最终 JSON 校验、usage 和输出绑定。
- `executionContext` 默认 isolated。项目场景直接使用快照 cwd，项目会话不持久化、不恢复、不与普通场景混用；Registry 不删除调用者源码目录。
- Pi 项目场景启用原生工具、保留 no-extensions/no-mcp。Codex 项目场景启用 shell/unified exec，使用 workspace-write/never 和 ephemeral thread，意外交互请求明确失败，不自动批准或搭建宿主工具桥。
- Codex 项目最终 JSON 与 commentary 分离；记录实际工具完成计数。项目运行不转发原始工具/诊断文本，仅输出安全生命周期、完成计数与用量；不承诺业务输出能自动过滤秘密。
- 成功/失败/取消清理临时资源并释放保留 ref；失败保留 lease、发安全事件并重试，不能改写业务结果。启动在 recoverBusiness 之后恢复；进程记录仍存活、PID 被复用或状态无法确认时保守保留，绝不盲目杀 PID/删除其工作区。
- 没有新增只读工具、项目沙箱、push 管理、配额、容量 GC 或删除按钮。普通节点与创作会话策略不变。

### 存储与界面

- `src/storage/usage.ts` 提供全数据目录的异步只读元数据扫描；分配/逻辑字节、普通文件数、数据库 WAL/SHM、隐藏与孤立缓存、硬链接去重、符号链接及跨设备排除、卷容量分别统计。
- 分类互斥，项目明细下钻；共享目录元数据/无法归属的临时资源单独列出，使项目缓存/临时合计不漏计。字节使用十进制字符串。allocated 不支持返回 null，不伪装为逻辑值。
- 并发扫描合并、内存缓存、刷新保留旧值；错误/取消/超时返回部分结果及计数，“已统计 + 未知”不把不可读取内容当零；维护或配置代次变化作废混合结果。
- 设置新增“项目仓库”“存储空间”，节点编辑器新增可选上下文，运行详情展示来源/阶段/完整 SHA 复制；没有私钥输入框。使用现有紧凑布局、主题变量、键盘焦点和窄屏滚动。

## 数据库与发布完整性

没有新增或修改表、索引、列、约束及迁移声明，不需要本 feature 的 schema-review。入队配置为权限受控内部运行 JSON，实际来源沿用 node_attempts.execution_json。
